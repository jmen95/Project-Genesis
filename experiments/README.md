# Experiments

Sandbox for spikes, prototypes, and technical experiments.

## Rules

- Experiments are isolated from `packages/` and `framework/`.
- Do not depend on experiments from production code.
- Document findings in [.cursor/memories/lessons-learned.md](../.cursor/memories/lessons-learned.md).
- Delete or promote successful experiments; do not let this directory grow unmanaged.
