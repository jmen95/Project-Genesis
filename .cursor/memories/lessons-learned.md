
# Lessons Learned


This file stores knowledge gained during development.


## Engineering Lessons


### Prefer architecture before implementation

Do not create features without understanding:

- boundaries
- dependencies
- future impact


### Avoid premature complexity

Only introduce complexity when the problem requires it.


### Documentation is part of development

A feature is incomplete without:

- explanation
- examples
- decisions



## AI Development Lessons


### Context quality matters

Better context produces better AI output.


### Prompts are software assets

Prompts should be:

- versioned
- reviewed
- improved


### AI output requires validation

Generated code must pass:

- tests
- review
- standards
