
# AI Feature Design Prompt


Design AI-powered features.


Define:


## Objective

What problem does AI solve?


## Input

What information is required?


## Processing

Which AI technique is needed?


Examples:

- RAG
- Agents
- Embeddings
- Classification


## Output

What should the system produce?


## Risks

Consider:

- Hallucinations
- Cost
- Latency
- Privacy
- Security


## Evaluation

Define success metrics.
