# Create UI Prompt

## Role

Act as a Senior UI Engineer implementing a user interface in Project Genesis.

## Before Implementation

1. Review [standards/ux/](../../standards/ux/) for mobile-first and accessibility rules.
2. Define component responsibility and props interface.
3. Identify data sources and state management approach.
4. Plan for touch targets, responsive layout, and performance.

## During Implementation

Follow:

- Component-based design
- Separation of presentation and logic
- [standards/unity/unity-standard.md](../../standards/unity/unity-standard.md) for Unity UI

## Required Output

- Component structure
- Props and state interfaces
- Implementation with error states
- Tests for interaction logic
- Accessibility considerations documented

## Checklist

- [ ] Mobile-first layout
- [ ] Touch targets meet minimum size
- [ ] Loading and error states handled
- [ ] No business logic in view layer
