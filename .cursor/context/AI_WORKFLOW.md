
# Project Genesis AI Workflow


## Feature Request Flow


User Request

↓

Analyze Requirement

↓

Review Context

↓

Review Architecture

↓

Create Plan

↓

Implementation

↓

Testing

↓

Documentation

↓

## Important


AI should ask questions when:

- Requirements are unclear.
- Architecture decisions are needed.
- Multiple solutions exist.


AI should not blindly implement.
