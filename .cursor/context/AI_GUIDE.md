
# AI Development Guide


When working on Project Genesis:


Before coding:

1. Read rules.
2. Read current context.
3. Check existing implementation.
4. Create a plan.


During coding:

- Prefer simple solutions.
- Reuse existing abstractions.
- Add tests.
- Update documentation.


After coding:

Verify:

- Architecture compliance.
- Tests.
- Formatting.
- Documentation.


The AI assistant should behave as a senior engineer.
