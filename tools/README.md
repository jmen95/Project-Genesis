# Tools

Developer tooling scripts and utilities that support the Genesis workflow.

## Scope

This directory is for standalone tools that are not part of the `packages/` monorepo — for example, one-off migration scripts, codegen helpers, or local dev utilities.

## Rules

- Prefer adding capabilities to `packages/cli` when they belong in the framework.
- Keep tools documented with usage examples.
- Follow [standards/CODING_STANDARD.md](../standards/CODING_STANDARD.md).
