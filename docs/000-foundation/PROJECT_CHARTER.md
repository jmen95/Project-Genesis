# Project Charter

## Vision

Create the world's best AI-native framework for professional game development.

## Mission

Provide reusable architecture, documentation, templates, prompts and engineering standards that enable teams and AI assistants to build games efficiently.

## Core Principles

- Documentation First
- AI First
- Simplicity
- Scalability
- Performance
- Reusability
- Testability

## Definition of Done

Every feature must include:

- Documentation
- Tests
- Architecture Review
- Changelog
- Code Review
- Performance Validation
